For this project, I made my LilyPad Arduino send Morse code through the Vibe Board which is a small motor that vibrates. Dots are short buzzes while dashes are longer ones. Normally, the board buzzes my name, GODWIN, but when I close the switch, it changes to SOS.

I used two alligator clips as my switch. One connects to the A9 tab, and the other connects to the negative (-) tab. When the loose ends touch, the circuit closes and the board plays SOS. When they are apart, it plays my name. I also connected the Vibe Board to the ~10/SCL tab and the negative (-) tab.

![My Arduino kit set-up](/assets/img/help-setup.jpg)

In the photo, the loose clips are apart, so the board is buzzing GODWIN.

Morse code depends on timing so I followed the rules we learned in class. A dash lasts three times as long as a dot, with a short pause between dots and dashes, a longer pause between letters, and an even longer pause between words. I used one base time and made the other timings multiples of it. This way, I only need to change one number if I want the messages to play faster or slower.

I also wrote a separate function for each letter. This made it easier to play my name because I could just call the letter functions in order. For SOS, I reused the same S and O functions instead of writing them again. I also followed the special timing rule for SOS which uses a shorter pause between letters.

**Extra credit:** I wanted the message to switch almost immediately when the clips touch or come apart even if it is in the middle of a letter. Instead of making the program wait for a long time, I broke the waiting time into smaller steps and checked the switch after each one. If the switch changes, the program stops the current message and starts the other one. I used a similar idea in my Fireflies project where I also had to keep track of timing without using one long delay.

**Tip for my past self:** Start with the basic version and get your name to buzz correctly before adding the switch. I also found it helpful to write out the dots and dashes for each letter so I could check the pattern since it can be hard to notice a mistake just by feeling the vibrations. Once I got my name working, adding the switch and the extra credit became much easier.
