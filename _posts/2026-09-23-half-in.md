This assignment was about practicing conditionals before we start using real buttons and switches. Since we haven't learned how to read those inputs yet we used two boolean variables `btn` and `swt` to simulate them. There are four possible combinations and each one should turn on a different colored LED. Only one LED should be on at a time.

To test my code, I changed the values of `btn` and `swt` manually and uploaded the code to see which LED turned on. I repeated this for all four combinations to make sure everything worked as expected.

For my conditionals, I decided to use `&&` instead of nested `if` statements. I found it easier to check both variables in the same condition rather than having an `if` statement inside another one. Since there are only four possible combinations, using `if` and `else if` made the code easier for me to read and understand. Each condition checks a specific combination and turns on the corresponding LED.

I think nested conditionals would be more useful if we had more variables or if several conditions shared the same first check. In that case, nesting could help avoid repeating the same conditions. But for this assignment, I preferred using `&&` because it was simpler and easier to follow.

One thing I would tell my past self is that assigning a value to a variable and checking its value are two different things. At first, I was confused about why I needed to check whether a variable was false when I had already set it to false at the beginning of the code. I now understand that an `if` statement checks the value of a variable when that line runs. This is why I can change the values of `btn` and `swt` without changing the conditional statements themselves.
